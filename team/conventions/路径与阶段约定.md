# 路径与阶段约定

> 本文件是人类可读的路径约定。机器可读唯一源：`.claude/reqflow/config.json`。两者必须同步；改路径时同时改 `config.json`、`.claude/CLAUDE.md`、本文件、`.claude/hooks/hooks-guide.md`。

## 方案根

```
个人/{作者}/{模块}/[功能名]/
```

- `{作者}`：中文名-工号，如 `张三-1001`
- `{模块}`：`team/conventions/模块清单.md` 中的七大模块之一；不属于具体模块用 `_通用`
- `[功能名]`：本次需求名称

## 七类产物

| 阶段 | 产物 | 目录 |
|---|---|---|
| 0 需求分析 | 需求论证 | `RequirementAnalysis/` |
| 1 需求推演 | 设计决策 | `DesignDecisions/设计决策_[功能名].md` |
| 2 可视化 | HTML 原型 | `VisualMockups/` |
| 3 PRD | 需求文档 | `PRD/01_[功能名]_需求文档.md` |
| 4 评审 | 评审记录 | `ReviewLogs/` |
| 全程 | 流程日志 + `state.json` + 标记 | `RequirementLogs/` |
| 5 复盘（可选） | 复盘总结 | `Retrospectives/` |

## 流程状态

```json
{
  "currentStage": "analysis | brainstorming | visual | prd | review | retro | finalized",
  "round": 1,
  "status": "active | finalized",
  "history": []
}
```

路径：`RequirementLogs/state.json`。由 `reqflow-state.js` 维护，hooks 读取。

## 定稿与归档

- 定稿：`state.status = finalized` + `RequirementLogs/.finalized`
- 定稿 ≠ 归档
- 归档：人工审批后复制到 `team/finalized-proposals/{模块}/[YYYYMMDD_功能名_作者]/`，流程不自动执行

## 校验

```bash
node .claude/scripts/reqflow-check.js --root "个人/{作者}/{模块}/[功能名]" --final --strict
```
