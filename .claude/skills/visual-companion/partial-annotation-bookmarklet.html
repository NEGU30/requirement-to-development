📐 局部标注 · 书签工具

独立的 HTML 局部标注工具。不修改 HTML 源文件，运行时注入。选中元素 → 写改动 → 导出清单给 AI。

🌐 推荐用 Chrome（谷歌浏览器）预览原型和标注——书签法在 Chrome 上一拖即装、点即用，体验最好、最省心。Edge 上书签受限（新建/编辑收藏都会被吃掉 javascript: 前缀），只能用第 1 步 ②控制台法（每次开 F12 粘一下）。所以标注任意网页，直接用 Chrome 最顺。
💡 先看这里：如果你标注的是 visual-companion 生成的可视化 HTML，无需本工具——那些 HTML 已自带标注器，打开后右下角就有 📐 浮动按钮，点开即用（Edge/Chrome/Firefox 都行，零安装）。
本页的书签版仅作为兜底，用于标注非 本流程生成的任意网页（比如线上页面、别处找来的 HTML）。
第 1 步：选一种方式安装/触发（Edge 用户强烈建议用 ② 控制台法）：

📥 局部标注

① Chrome / 能正常拖拽的浏览器：直接把上面蓝色按钮拖到收藏栏即可，一步到位。

② Edge · 控制台法（最稳，推荐）：点「复制控制台源码」→ 打开任意要标注的网页 → 按 F12 → 切到 Console 标签 → Ctrl+V 粘贴 → 按 回车。标注器立即在该页生效。不经过书签，绕开 Edge 所有限制。每次开 F12 粘一下即可。

③ Edge · 书签法（实测新版 Edge 常失效，不推荐）：理论上可"先收藏一个正常网页 → Ctrl+Shift+O 编辑其 URL → 替换为书签代码"，但新版 Edge 编辑时也可能剥离 javascript: 前缀、且长 URL 易被截断，存成的书签多数点不动。Edge 用户请直接用 ②控制台法，或更省心地改用 Chrome（书签法①一拖即装）。

第 2 步：打开要标注的网页（任意网页均可，不限可视化 HTML）。
第 3 步：触发标注器——书签用户点收藏栏的「📥 局部标注」；控制台用户已在上一步 F12 粘贴执行。页面顶部出现标注工具栏即成功。
第 4 步：点「开启标注」→ 鼠标悬浮高亮元素（F12 式）→ 点击选中 → 写改动 → 确认。可标多个。
第 5 步：点「导出清单」→ 复制 → 贴给 AI。AI 按 selector 在源 HTML 里定位元素、按改动描述修改。

导出的清单长这样：

1. .cal-grid .cal-event:nth-child(2) | <div class="cal-event">10:30 家长会</div> | 颜色改浅
2. .mock-btn | <span class="mock-btn">新建日程</span> | 文字改成"立即创建"
3. .cal-head:nth-child(3) | <div class="cal-head">周三 17</div> | 背景改成黄色

每条 = CSS selector（AI 按此定位元素）+ 元素签名（实况）+ 改动描述。AI 拿到后直接按 selector 改源 HTML，不用猜。
