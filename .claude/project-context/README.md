# 项目背景

本文件夹存放**本项目**的背景资料，供 本流程的 AI 在需求分析、推演时建立产品认知。

## 用法

- **可单可多**：放一个概要文档，或拆成多个（项目概要、模块说明、架构图、用户画像、术语表……按需）。AI 会读取本文件夹下**所有**文档作为项目背景。
- **文件名随意**：不绑定具体项目名，起任何有意义的名字都行。
- 安装本流程时，把你项目的背景文档放进这个文件夹即可，**不用改任何 skill 文件**——本流程是项目无关的。

## 不知道怎么写？

一个典型的项目概要通常包含：产品定位、模块构成、架构、用户场景。按这个结构写即可。

## 哪些 skill 会读这里

- `requirement-pipeline`（总控）：声明项目背景位置
- `brainstorming`（推演）：开始设计前必读本文件夹，确保方案与产品定位一致
